# 本地 InDesign 画册排版

本技能随 AlbumGenie 仓库使用，项目根目录是本目录向上三级。将内容与设计关系交给 Nutria MCP，由本地 InDesign 重排、置图、保存和导出；保留原生文本、Story、样式与链接。HTML/CSS/SVG 是设计来源，不是任意网页自动转换器。

先读[项目全局经验](../../../docs/memory/global.md)和[经验维护流程](../../../docs/memory/README.md)，识别当前画册后读取本地 `.local/albums/<album-id>/MEMORY.md`。本地文件不存在时按共享模板创建，不加载旧客户案例。仅维护文档或技能时不启动排版、安装依赖或重跑生产。

## 执行顺序

1. **确认新画册方向。** 新画册或另起整体设计时，明确用途／受众、整体风格、色彩倾向、语种及中文画册是否允许英文装饰。已有决定直接带入；提出有区别且与品牌相容的候选色板，形成含字体层级、封面方向、图片主次、网格和跨页节奏的方向规划。用户确认规划后实施正式代表页与排版；已确认方向内的局部修改无需重做启动确认。
2. **固定范围和输入。** 保存原件、来源编号、页数及封面计数、尺寸、装订、出血、文案权限和独立版本；待定印刷条件如实记录。保持全部原生文字框单栏，用多个框形成视觉分栏，同篇Story按阅读顺序串联。
3. **先检查 MCP，再检查现场。** 发现当前会话工具并做只读连通测试；没有工具时按[检查与安装说明](../../../docs/indesign-mcp-setup.md)区分未注册、未构建、缺依赖与未安装，已有可用连接不重装。上游工具与本地 `album_*` 扩展分别核实，不能用安装成功代替能力验证。然后查询字体、预设和桥接，列出文档完整路径及 saved／modified，先保护用户新现场；写入校验本轮token与路径，COM串行，超时先查状态。
4. **规划篇章与选组件。** 先安排真实 Spread 和上下文，再按角色、语言、容量、数量、图片比例选组件或自由设计。使用 `tools/design_library.py` 检索；候选与验证状态不能混写。将选型和本册适配记入本地组件使用记录。
5. **验证代表页，再完成全书。** 新实现先查原生编辑、重排、溢出恢复、字体、链接、几何与 IDML 保留；已有能力实现不变时复用证据。保留完整正文，不为容纳内容擅自删字、补译或降低可读性。按批次保存检查点。
6. **从实际交付验证。** 保存 INDD → 原生导出 IDML → 核实自有文档并重开交付 IDML → 全书核对 → 导出 PDF。逐页渲染查看，分别检查正文、字体嵌入、页面框、ICC和实际出血；移位和负向检查只用自有副本。
7. **交付与记录。** 按本地日志模板记录成果、证据和待办，分开技术、Agent视觉、用户视觉及印刷状态。新反馈先落实已有授权；拟保存长期经验时展示文本并询问全局／本册／不持久化，确认后写相应经验文件。不能把用户提出一次修改理解成新全局规则。

目标不匹配、上次调用完成状态不明或恢复可能影响未保存文档时，先保留现场并继续可独立的资料与检查工作。任何旧案例的 token、安装／重启许可与具体坐标都不自动适用于本轮。
