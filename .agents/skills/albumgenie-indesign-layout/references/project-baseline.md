# 历史案例与本地基线

共享技能不内置客户名称、原稿位置、固定token或当前交付页码。接续本机旧任务时：

1. 读取项目 `.local/STATE.md`，选择本次画册，不混用其他画册。
2. 读取 `.local/albums/<album-id>/MEMORY.md` 与最近 `.local/任务日志.md`；完整历史位于 `.local/archive/`、`feedback/`、`validation/`、`output/`。
3. 重新查询真实打开文档的路径、saved／modified 与当前用户手改；历史“已打开”“零溢出”不保证当前状态。
4. 阅读活动脚本中的固定路径、页数、摘要、token和一次性检查点；保存现场副本后按本轮任务适配，不盲跑。

`.local/` 不存在的新克隆没有客户案例，不因缺少旧日志而阻塞新的资料清点或排版。用[画册模板](../../../../docs/templates/album-memory.md)和[日志模板](../../../../docs/templates/task-log.md)建立本次记录。通用能力只在本次环境和实现相同的前提下复用证据。
