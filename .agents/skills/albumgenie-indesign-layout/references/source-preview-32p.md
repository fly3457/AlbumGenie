# 源码设计与原生生产

本文件保留历史入口文件名，内容为可复用方法；旧案例页数不是新任务默认值。

1. 固定同一输入与独立版本。以纯文字来源ID、完整段落和素材摘要建立布局数据，保存标题／正文角色、网格、分组、字体实例、尺寸、颜色及裁切，不只存散落坐标。
2. 用HTML/CSS表达页面与文字关系，SVG表达复杂图形。按已确认方向使用实际字体和完整文案，先看代表页、成品尺度与跨页。不能把参考截图直接当设计源码。
3. 从实际DOM的结构、计算样式和几何导出元素级数据，与来源ID和稳定对象名关联。文字→原生TextFrame／Story／样式，简单色块／线条→原生对象，照片→原图链接及原生裁切，复杂矢量→链接SVG。
4. 校准两个引擎。CSS px／line-height与InDesign mm／pt／leading有不同语义；浏览器和原生的换行可以不同。依实际行内容、框高和溢出调版，保留完整段落，不为逐行相同拆框或塞硬换行。
5. 新组件或效果先验证映射边界；不支持的效果明确适配，不悄悄栅格化整页。字体名、可变轴、色板及ICC独立记录，不从截图反推印刷色。
6. 对照源码与原生的构图、轴线、主次、文字层级、图片取景和装饰；再检查原生编辑、全文、真实IDML及PDF。往返保真与设计美观是不同结论。

没有已验证的通用网页一比一转换器。共享工具当前负责组件查找和静态检查，历史全书构建脚本留在本地；新机器不因拥有HTML便已具备原生生产能力。
