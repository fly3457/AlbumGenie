# 参考分析与方向规划

用户提供参考画册时，原件留在本地输入目录，先确定希望借鉴的特点与允许范围，再分析风格；仅公开可访问不代表素材允许再分发。

分析完整跨页的层级、版心、字体关系、色彩角色、图文比例、装饰和节奏，区分可复用的设计关系与原作内容。不复制Logo、客户文案或未经许可的生产照片。

需要建立Moodboard时使用随仓库提供的 [moodboard-builder](../../moodboard-builder/SKILL.md)，记录候选与用户认可；这是方向规划工具，不是每次局部修改的固定步骤。已经有完整参考与已确认方向时直接复用，不为满足通用品牌流程额外搜索或另建情绪板；落地媒介固定为本次画册，不沿用其通用网页默认值。用户指定字体时核对本机文件、命名实例和可变轴，字体许可另行记录。

将用途、风格、色板、语种／英文装饰范围、字体层级、封面、图片主次、网格和章节节奏形成可审核的方向规划。用户确认后进入正式代表页；参考分析或Agent自查不等于整份方向已确认。已确认方向内的续作直接继续。
