# 排版与验收流程

本文件用于内容已确定后的实际排版和交付检查。当前文案、源图及脚本入口按 [本地记录](project-baseline.md) 定位，连接问题见 [Windows / Nutria](windows-nutria.md)。

## 原生文字与字体

- 每个正文块写完整段落，保留原生 TextFrame / Story 和 ParagraphStyle。按视觉需要分中文与英文框，避免按每一行建独立框、转曲正文或将整页栅格化。
- 对段落应用样式时遍历 `tf.parentStory.paragraphs`。`tf.paragraphs` 只覆盖框内可见段落，溢出部分可能漏掉样式。
- 本项目中文叙述正文默认首行缩进两字（本册明确特例优先），使用段落属性而非改写文本。字号pt与缩进mm分别换算；检查实际段落、ParagraphStyle、首行起点及IDML重开保留。标题／标签／联系方式等角色和英文不机械套用，范围见[排版规则](editorial-design.md#正文缩进标题断行与重点元素)。
- 替换内容使用 `tf.parentStory.contents`。溢出时写 `tf.contents` 可能只替换可见部分，遗留隐藏文字，造成重复内容。
- 审核同时读取 `parentStory.contents`、框的可见内容、行数、`tf.overflows`、`story.overflows` 和实际段落样式。跨框 Story 以唯一 Story 核对全文，另核对每个容器的可见部分。
- 设置字体前检查 `itemByName(...).isValid` 和 `status=INSTALLED`；字体名字出现在环境列表里不能证明可用。实际名称可以是 `Noto Sans SC\tRegular`，应用字体对象，记录最终名称和状态。
- Windows COM 下逐字体读取 `fontFamily` 等属性曾报错；优先使用已验证的 `name/status/postscriptName`。按多字重内容核查实际文字范围，不能仅从文本框首字符推断全框字体。
- 技术证据至少包含增添中文、收窄框、改样式、溢出/恢复以及保存重开。一个有文字的框、合法 XML 或 PDF 中可选中文字，并不充分证明原生编辑和自动续排。

## 几何、出血与素材

| 项目 | 做法 |
| --- | --- |
| 单位 | 页面、边距和几何使用 mm；字号、行距使用 pt。`spaceAfter` 等段落间距在当前桥接中跟随文档单位：文档为 mm 时，期望的 pt 需乘 `25.4/72`。创建后读取实际尺寸，不能将裸数字都当 pt |
| 页内到跨页坐标 | 采用 `SPREAD_ORIGIN`、`zeroPoint=[0,0]`；将页内边界加实际 `page.bounds` 的 top/left。`PAGE_ORIGIN` 再加偏移会重复定位 |
| 左右页 | 从实际页面 side、spread 和边界判断；不要把奇偶页规则推广到不同起始页或封面结构 |
| 内侧出血 | 内页背景/照片不越过相邻页成品边：右页页内 left≥0，左页 right≤页宽；外缘依要求延伸。封面、书脊与展开另按装订规划 |
| 图片裁切 | 有人物、标牌或完整图注时优先检查 contain；fill 用于允许裁切的照片。检查实际裁切和有效 PPI，两轴都记录 |
| 图像质量 | 以印刷尺寸下有效 PPI 和原图质量为准；减少占版或补原图。放大重采样不能作为恢复原始细节的证据 |
| 矢量 | 关系图等可作为链接 SVG 置入，关键文字标签使用原生文本；置入素材的内部路径可编辑性与正文可编辑性分开说明 |
| 色彩 | 文档原生 CMYK 色板、图像转换、实际 PDF 输出和 ICC 配置分别核对；SVG 含 `icc-color()` 不能证明最终 PDF 为正确 CMYK |

为素材记录原件摘要、派生方式和使用页。保留源图，仅在独立资源目录裁切或派生矢量。小字号黑字采用单黑可减少套印风险，但品牌色、字体和黑版方案按本次设计及印刷要求选择。

## 检查矩阵

按本次产品能力安排测试，测试文档与交付版本隔离。新增实现先过代表页，再检查整本；已有实现没有变化时可复用证据并核实本次输入和输出。

| 检查 | 有意义的证据 | 防止错误结论 |
| --- | --- | --- |
| 文案完整性 | 源段落 → 清洁 Word → 原生 Story → IDML → PDF 的对应；规范化换行/空白后核对正文及数字 | 不通过删标点、删段落或仅统计字符数量掩盖遗漏；重复标题仍需来源对应 |
| 原生编辑 | 修改文字、框宽、段落样式、图片，保存 INDD/IDML，分别重开检查 | 使用验证副本，不覆盖交付和手改稿 |
| 跨页流动 | 一个 Story、两个容器、各自有可见内容、全文一致、重开仍续排 | 两个独立相似框不能算续排验证 |
| 溢出负向 | 故意缩框可检测到溢出，恢复全文及框后清除；全书最终框/Story 均零溢出 | 仅检查可见段落会漏掉隐藏溢出 |
| 字体/链接 | 所有实际使用字体 INSTALLED，链接 NORMAL，路径正确 | 链接正常也可能读的是原目录缓存资源 |
| 缺图负向 | 自有测试图隐藏后能报 LINK_MISSING，恢复后 NORMAL | 避免使用客户原图做隐藏测试 |
| IDML 往返 | 全页对象、文字、段落样式、字重/字号、几何、图片及溢出一致 | 排除内部对象 ID；多样式框增加范围级核查 |
| 全书视觉 | 全页渲染并查看；相同预设/分辨率的 native 与 IDML PDF 逐页比较 | 不能从抽样几页推广到全书，像素一致也不替代用户视觉认可 |
| 移位恢复 | 复制整包，隐藏原生成 Links；重开副本，所有路径解析到副本资源 | 本机已有字体不等于新机器自动激活字体 |
| 重建一致性 | 用同一参数重建指定代表页，比较语义、几何、续排和图像 | 对两页的结论限定为两页，不能写整本完全可复现 |

## PDF 导出和文件检查

1. 重开实际交付 IDML 后导出最终文件，记录实际预设、InDesign 版本、色彩配置和出血设置。校对 PDF 与印刷技术样本分别命名。
2. 查询本机预设名。按当前安装环境发现可用预设，不能照抄旧环境名称。用临时 preset 对象副本，单页导出，恢复全局 PDF preferences 并清理副本。
3. 校对 PDF 关闭文档出血并将预设手动四边出血设为 0；只关闭 `useDocumentBleedWithPDF` 而保留预设数值仍可能有意外出血。印刷版本使用本次已设置的文档出血，裁切标记等按印厂要求。
4. 需要 CMYK 转换时明确设置 `PDFColorSpace.REPURPOSE_CMYK`、`pdfDestinationProfile` 和 `pdfXProfile`，核对文档实际 ICC；不能把历史案例色彩配置当作默认印厂配置。
5. 检查所有页面的数量、MediaBox、TrimBox、BleedBox，按 `1pt=1/72in` 转成 mm。留意定义了页面框与实际画面确有出血是两项检查。
6. 通过 PDF 字体资源及 DescendantFonts/FontDescriptor 的 FontFile* 检查嵌入，并核对正文覆盖。工具随环境发现；缺少 `pdffonts` 时可用 pypdf 读取资源。
7. 印刷样本检查 PDF/X 版本标识、OutputIntent、ICC 通道数和配置身份，递归遍历图片/Form 颜色资源及页面颜色操作。RGB 操作消失只是部分证据；专色、透明度和完整标准合规另需相应检查。
8. SVG 在 PDF 中可能内联为页面路径，不一定保留 Form XObject。检查对应页面的贝塞尔/直线等路径及图片对象，必要时递归 Form；不要把找不到 Form 当栅格化失败。

PDF/X 预设加结构检查可以证明技术输出的若干条件。完整合规认证、印厂认可和最终发布须按实际生产规范预检；本 skill 不授予外部发布权限。

## 交付记录

交付目录至少对应：原生文件、交换文件、PDF、Links、允许分发的字体及许可、色彩配置说明、全页预览、来源映射和验证报告。记录资源真实文件名、摘要及裁切/派生关系，使用相对路径说明，打包后验证 CRC 和清单。

报告填写四项独立状态：技术检查结果、Agent视觉自查、用户视觉验收结果、印刷发布条件。注明清晰度不足、源稿翻译问题、缺素材、待确认尺寸/装订/ICC，以及尚未测试的专色、工艺、封面展开等范围。用户开始手改后另存版本；重新按布局定义生成会覆盖人工设计，需先处理差异。
