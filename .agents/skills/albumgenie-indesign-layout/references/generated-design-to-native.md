# 生图设计稿到原生完稿

仅在用户要求或已确认的工作流采用生图先行时使用。固定准确文案、原始Logo、成品尺寸与已确认方向，调用当前可用且符合用户偏好的生图工具生成完整设计稿，记录工具实际报告的模型、提示词、参考和原始结果，不猜底层版本或上采样冒充原尺寸。

检查品牌识别、文字内容、构图、层级、对齐、留白、色彩与成品可读性，不合格则迭代。用户已授权Agent自行审核并实施的，审稿通过后直接制作；若用户保留方向审批，则在相应阶段提交具体稿件。Agent通过不等于用户最终视觉认可。

原生完稿忠实保留通过稿的构图关系。标题、正文及图注重建为原生文字，Logo置入准确原件；必要时另生成无字主视觉，不能把整张有字图当作可编辑交付。记录主视觉原尺寸及有效PPI，保留来源与生成声明。

查看设计稿与实际原生稿的同尺度对照，检查字形准确、完整文案、图片取景、轴线和视觉分量；再完成编辑、溢出、实际IDML重开与PDF检查。历史任务的具体封面风格和审稿授权不自动应用于下一册。
