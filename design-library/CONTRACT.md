# 组件信息约定

`registry.json` 是共享组件的唯一索引，保存 schemaVersion、用途分类及组件元数据路径。每个 ID 在索引中出现一次，元数据 ID 与目录名一致。`v1/` 不参与共享索引；本地工具加 `--include-local` 后补充本地独有 ID，共享 revision 优先。

## 每个组件

```text
components/<ID>/
  component.html    完整段落、插槽和图框，不能是截图
  component.css     静态布局关系，不含本册品牌约束
  preview.html      独立原尺寸演示，与组件引用同一基础样式
  metadata.json     来源、语义、容量、几何、版本及验证状态
```

| 字段 | 含义与使用方式 |
| --- | --- |
| `id`、`revision`、`origin` | 稳定 ID、当前修订、迁移来源及旧修订；同 ID 的本地历史与共享版本分别识别 |
| `category`、`subtype`、`tags` | 七类用途及数据图／概念／流程等语义分类；不按示例颜色或客户行业分类 |
| `useWhen`、`contentCapacity` | 内容角色与容量说明，含文字长度、照片数量及限制 |
| `selection.languages` | 演示源码已有的语种，不能推断新语种已适配 |
| `selection.itemCount` | 已说明的重复项范围，null 表示未定义；数量指照片还是信息项见 itemCountMeaning |
| `frameMm`、`contentFrameMm`、`geometry` | 外画布与内容范围、轴线、比例和间距；示例尺寸不是生产容量下限 |
| `slots`、`parameters` | 可替换的完整文案、图片、图标、色彩及CSS变量，不写回客户示例数据 |
| `sourceReferences`、`distribution` | 原作、固定提交、许可文件、是否含客户素材、项目许可证标识 |
| `nativeMapping` | 原生文字／形状／图片／复杂矢量的映射方法及边界 |
| `validation` | 静态检查入口、浏览器、原生验证和用户视觉状态，各自独立 |
| `files` | HTML/CSS/预览的当前 SHA256；改动时更新修订与摘要 |

基础字体、色彩、间距及页面尺寸只在 `foundations/` 定义演示值。字体只登记固定来源和摘要，二进制首次使用时下载到忽略的缓存，不进入Git历史或发布包；静态check允许清单中声明的字体尚未缓存，`check --require-fonts`检查缓存完整性，任意其他缺失资源仍报错。共享层不保存某一画册的全文、Logo、页面坐标、客户照片或本机路径。可复用复杂SVG置于 foundations/vectors；本组件独有资源可放在本组件目录，并由依赖检查核实。

本次共享28件为修订2：替换客户照片、去客户标签、去本机方圆可变字体依赖。原来的DOM几何、浏览器／视觉检查不沿用为本修订结论。12件参考截图转化组件留在本地原库，待确认可分享性并完成同样清理后再提取。

## 验证与入库

1. 建立独立原始源码，填写实际语义、完整插槽、容量、来源及必要许可；`registry.json` 增加条目并同步分类数量。
2. 运行 `python tools/design_library.py check`，检查当前源码摘要、元数据、相对资源、字体、来源与许可文件。该工具不启动网络、浏览器或InDesign，不能证明视觉或原生通过。
3. 对默认、长文本、不同数量／宽度／语种、换图标、换图和换色场景渲染并查看。声明哪些变体实际通过，不把超出说明的用法写成支持。
4. 原生验证在真实文案与本册尺寸下进行。正文连续TextFrame／Story，简单形状原生对象，照片为链接原图及原生裁切，复杂矢量可保持SVG链接；检查编辑、重排、零溢出与实际IDML重开。
5. 将证据与验收范围留在本地画册使用记录；若要提升共享组件的原生状态，公开去客户化的可复现代表页证据后再更新，不能只沿用某本画册的私有“通过”。
