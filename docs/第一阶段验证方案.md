# 本地画册排版验证方案

本文件是可复用方案。历史客户的版本、参数与实际结论保存在本地任务日志，不作为新画册的默认配置。按[排版技能](../.agents/skills/albumgenie-indesign-layout/SKILL.md)执行；用户只整理记录时不启动生产。

## 输入与范围

资料放在 `input/<album-id>/`，保留原件。按[画册记忆模板](templates/album-memory.md)登记用途、风格、语种及英文装饰范围、文案权限、页数与四封面计数、尺寸、装订、出血、字体、品牌色和印刷条件。已有用户决定直接带入，未定项说明影响。

清点正文、表格、图注、Logo与图片，给内容建立稳定来源ID。先提出可审核的方向规划并记录用户确认，再设计代表页和完整页面。现有方向内的续作与修复不重复启动确认。

## 代表页验证

选覆盖本次内容的代表页：密集正文、照片、双语／表格或复杂矢量；不固定数量或照搬旧客户页序。保护实际打开文档，在自有副本中检查：

1. 原生正文增字、收窄框、改样式后自动重排，全文不丢失。
2. 本次需要的跨框Story连贯，强制溢出能报告并恢复。
3. 图片替换、裁切、字体及页面坐标正确；新增组件先做真实内容验证。
4. INDD和原生IDML分别重开，内容、几何、字体、样式与续排保留。

环境或实现未变时复用已有能力证据，新增或异常的能力补相应检查。

## 全书与交付

全书检查来源文案、授权删除、页序／Spread、字体、链接、图片质量、框／Story溢出及出血。逐页渲染查看实际成品尺度，按[组件使用模板](templates/component-usage.json)记录复用与适配。

保存INDD → 导出交付IDML → 实际重开该IDML → 全页核对 → 导出PDF。分别核对校对与印刷文件的页数、页面框、正文、字体嵌入、ICC与真实画面出血。移位与缺图恢复仅使用自有测试副本。

最终交付原生稿、IDML、PDF、合法可分发的Links／字体及来源记录。任务日志按[模板](templates/task-log.md)记录实际检查范围和证据；技术通过、Agent视觉自查、用户视觉认可与印刷放行分别填写。
