新经验须经过[用户确认与范围选择](README.md)后增加；候选不在本文生效。本册确认的特例及用户当前指令优先于这里的默认规则。具体字号、页数、字体、色板和 ICC 按当前画册约定；技术通过不代替用户视觉认可。

## 设计经验

1. **G-001 · 先规划篇章，再设计单页。** 多页篇章尽量以真实面对的左、右页起篇。核对同一Spread和页侧，统筹首跨页的标题、图像、正文及留白；页码相邻不足以证明是阅读跨页。目录随页序更新。
2. **G-002 · 先理解上下文，再分栏。** 标题、短开头与后续主体尽量同栏；主张与“这句话”等解释邻近呈现。完整信息点优先成组，上一节收束后再开启新节。不要因机械均分栏高而拆散联系紧密的段落。
3. **G-003 · 跨页共用实际对齐基准。** 并列同级标题的文字基线、其后正文的起始基线一起安排。文本框顶端相同不等于字面或基线对齐；不能用空白段落或改变既定字号、行距来凑齐。
4. **G-004 · 同级统一，不同级有区别。** 全书同级字号、字重、组距及装饰保持一致；不同层级使用可区分的表达。装饰需有节制，细线／短条与标题保留净间距，不能压迫文字。封面、封二、封三、封底按各自角色安排，不把留白封面硬塞成正文页。
5. **G-005 · 正文参数稳定，局部按语义精修。** 普通段后距沿用约定；连续排比、步骤及清单内部可采用已授权的紧凑组距，组末再留距。避免单字／两字短尾行：保持字号，先微调可用栏宽，再小幅调整字格、字距或字宽；必要时把末尾短词组设为原生不可拆分，保留原文字符。记录局部参数并检查后续重排及IDML保留。短清单项、完整短引述可用原生整段保持，避免被分栏机械切开。
6. **G-006 · 图标、标题和说明组成一个精细元素。** 核对图标实际可见轮廓，消除非预期白方底；图标与文字按顶部或垂直中心对齐。卡片圆角、边线、内距及组间距一致，不能只设容器坐标便视为精修完成。
7. **G-007 · 照片墙先成为整体，再与正文对齐。** 同组照片集中，实际可见边缘的间距一致；按主体合理裁切。每张图注直接放在对应图片下方，并与图片左边缘对齐，使照片与说明形成清晰单元；不把多图说明集中到组底再依靠“左上／右下”等方位标签查找。图组再与正文共用清楚的轴线。人物、标牌和关键信息优先保护；合影完整放单页，关键人物避开装订线。真实历史图片与生成意象分清来源。
8. **G-008 · 留白服务主次和阅读。** 图多字少的跨页可采用一侧照片、标题／日期等重点文字，另一侧集中正文；需要时保留完整首段平衡分量。不要把少量尾文与大块无作用留白单独留在续页，也不编造口号填空。
9. **G-009 · 以实际成品验证。** 看全书节奏、真实跨页和成品尺度细节；核对全文、授权删除、页码、实际行内容、字体、图片裁切、溢出及出血。保存独立版本，检查可编辑原生稿与实际重开IDML；逐项反馈有实施位置和证据。
10. **G-010 · 先用生图验证设计，再按通过方案原生完稿。** 用户要求生图先行时，先固定现有文案、客户Logo、尺寸与已确认方向，生成包含文字和主视觉的完整设计稿；由Agent自行审核品牌识别、文案准确性、层级、对齐、留白、配色及成品尺度可读性，不合格则迭代。用户已授权自行审核的，审核通过后直接制作，不重复等待启动确认。原生完稿应忠实还原通过的构图；标题、正文、标志等用可编辑文字和准确的客户资源重建，不能把整张有字生成图当作完稿。必要时另外生成无字主视觉用于置入，并记录模型、提示词、参考图、生成结果、审稿结论及设计稿与完稿对照。Agent审核通过与用户最终视觉认可分别记录。具体流程见[生图设计稿到原生完稿](../../.agents/skills/albumgenie-indesign-layout/references/generated-design-to-native.md)。

11. **G-011 · 文字框高度贴合实际内容。** 字格指原生文本框。固定栏宽和文字起始位置后，按实际排入内容收紧框底，去除人为预留的多余空高；不用扩大框或附加空段落制造留白。目录标题、页码与分隔线按实际文字及共同轴线安排，不能依赖含大块空白的框底对齐。收紧后核对末行、下伸笔画、段后距和溢出，保留必要的排版安全量。
12. **G-012 · 统一单栏框，以原生文本串联组织文章。** 全项目原生文字框使用单栏；双栏视觉布局由两个单栏框组成。同一文章、同页或同一阅读跨页的连续内容用同一Story按阅读顺序串联，并用每个框的实际宽度与高度控制内容分配。独立文章不混链，目录独立条目和卡片不强行串联；标题、主张和相应正文的关系仍按语义安排。转换多栏框或合并Story时完整保留文字、样式与局部字距，检查没有丢文、重复、空容器或错误续排。
13. **G-013 · 中文正文默认两端对齐、末行左对齐。** 采用InDesign原生段落对齐属性，不用手工空格撑齐。普通中文正文及叙述段落统一执行；标题、页眉、目录页码、英文装饰和具有独立设计作用的短标签按各自角色处理。与既定字号、行距、首行缩进、段后距及短尾行控制共同检查，并核对实际IDML保留。
14. **G-014 · 页面过空时平衡图文分量。** 除非整本画册采用统一的大面积留白设计，否则页面出现无作用的大块空白时，应结合相邻跨页重新分配图片、正文与留白；没有合适图片时，可以用浅灰色图片占位优化版面。占位与正文共用清楚的轴线和图文间距，并明确登记为待补素材。保留完整内容与既定正文参数，不靠扩大空文本框、编造文案或随意放大图片填空，也不要求每一处留白都被填满。具体图片比例和文字位置按篇章内容决定。

## 生产与协作经验

15. **G-015 · 完整段落与完整 Story 是内容核对单位。** 不按每行拆框、不将正文转曲或以整页位图代替原生编辑。替换全文用 `parentStory.contents`，对段落样式遍历完整 Story；逐个唯一 Story 核对全文，另查各容器可见内容、行数和溢出，避免遗漏隐藏文字或重复计数。
16. **G-016 · 单位、坐标与字体须读回。** 页面几何用 mm，字号和行距用 pt；段距等属性先核实当前单位。页内坐标按实际原点及 `page.bounds` 转换，检查真实 Spread 和页侧。核对实际安装字体、命名实例及可变轴，不能由 CSS 字重或 PDF 字体别名推断原生实例。
17. **G-017 · 保护实际用户现场。** 继续修改前读取打开文档的完整路径、saved／modified 状态，先保存独立现场副本；不用旧布局 JSON 覆盖用户手改。写入时同时校验归属 token 和路径；旧 token、同名文件及旧日志都不证明当前归属。
18. **G-018 · COM 操作串行，超时先查状态。** 调用超时不等于 InDesign 操作已取消。停止依赖写入、读取实际文档与检查点再恢复，不能盲重试或强制结束应用。已有无关和未保存文档保持现场；需要改变它们时依据当前授权处理。
19. **G-019 · 从实际重开的交付 IDML 验证与导出。** 保存 INDD、原生导出 IDML、重开实际交付 IDML，核对全文、范围级样式、字体、几何、链接、续排和溢出，再导出 PDF。忽略内部对象 ID 等非语义差异；PDF 的页数、页面框、正文、字体嵌入、ICC 和实际出血分别检查。
20. **G-020 · 检查必须能发现错误，并限定结论范围。** 编辑、强制溢出和缺图恢复在自有测试副本进行，用 finally 恢复临时资源。移位测试要求链接解析到副本。集合比较先断言页数与对象数量，不能用空集合得到假通过；抽样、静态资源检查和本机字体检查不能写成全书、浏览器交互或异机通过。
21. **G-021 · 来源与画质如实记录。** 保留原始图片和 Logo，图注按证据配对；客户图、官网图、开源图与生成意象分别标记。公开可访问不等于有再分发许可，放大重采样不恢复细节。原图质量与有效 PPI 按实际尺寸核查，数值阈值由本次输出要求决定。
22. **G-022 · 设计预览与原生生产按元素衔接。** HTML/CSS 负责组件与页面关系，SVG 负责复杂图形，原生文字、形状、链接与裁切按结构及实际几何重建。浏览器与 InDesign 的换行和单位需要校准；不存在本项目已验证的任意网页一比一转换器，不用整页截图代替可编辑交付。
23. **G-023 · 组件按内容层级选型，保留语义。** 先看角色、语种、字数、条目数、图片比例与可用宽度，再选组件或自由设计。同级协调、异级可辨；示例文案、英文、颜色、图标及数量不是客户内容。数据占比、概念关系和流程先后不能互换；容量不足时重排，不为套组件删文。
24. **G-024 · 分开记录四类验收。** 技术检查、Agent 视觉自查、用户视觉认可和印刷发布分别记状态及证据。像素往返一致证明保真，不证明设计美观；PDF 预设和结构检查也不等于独立的完整印刷合规认证。待定纸张、装订、ICC、高清原图及异机字体条件随交付说明保留。
